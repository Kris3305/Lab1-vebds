# Персональний сайт Стівена Кінга

Це лабораторна робота з дисципліни "Веб-технології та веб-дизайн".
Сайт присвячений біографії та творчості американського письменника Стівена Кінга.

## Технології
- HTML5 (семантична розмітка)
- CSS3 (блочна модель, позиціонування, стилізація форм)

## Структура
- `index.html` — головна сторінка (біографія, таблиця, списки)
- `contact.html` — сторінка з формами та демонстрацією позиціонування
- `css/styles.css` — спільні стилі
